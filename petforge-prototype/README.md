# PetForge 중독성 프로토타입

> PetForge의 중독성 강화 기능을 시각적으로 검증하기 위한 프로토타입

## 데모

http://115.71.237.101:8081/

## 기능

- ⚡ 빠른 배틀 (30초 핵심 루프)
- 🔥 연승 보너스 시각화 (3/5/10)
- 🎰 승리 룰렛
- 🌌 성운 시너지
- 🔮 유물 슬롯 시스템
- 🎫 배틀패스 (무료/유료 트랙)
- 🌠 주간 시드 던전
- ⚔️ PvP 아레나 + 티어
- 📖 도감 세트 보너스 (전투 반영)
- 📜 스토리 카드 + 보스 컷신

## 파일

- `index.html` — UI
- `proto.js` — 게임 로직
