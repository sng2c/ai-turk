# PetForge 중독성 폭발 게임화 기획안

## 1. 현재 게임 진단

- **장르**: 펫 수집 · 교배 · 턴제 배틀 · 행성 정복
- **핵심 루프**: 수집 → 교배 → 육성 → 배틀 → 행성 점령 → 마켓/퀘스트
- **현재 콘텐츠**: 4기본 종족 + 20+ 혼혈 / 4성운 24행성 / 63개 스킬 / 10개 상태이상
- **가장 큰 강점**: 교배 시스템(세대, 등급, 능력치, 기술 승계)이 깊음
- **가장 큰 약점**: 즉각적 보상/긴장감/경쟁/시간제 콘텐츠가 약함

---

## 2. 중독성을 높이는 7가지 방향

### A. "30초 핵심 루프" 보상 폭발
- **즉시 전투**: 메인 화면에서 "⚡ 1분 배틀" 1회 클릭 → 바로 전투 + 보상
- **연승 보너스 시각화**: 현재 100% max → 단계별 불꽃 이펙트 + 추가 보상
- **배틀 후 룰렛**: 승리 시 3회 무료 골드/아이템 룰렛(광고 시 +2회)
- **첫 승리 보상 2배**: 일일 첫 승리 시 보상 2배(매일 복귀 동기)

### B. 로그라이크 메타 진화 (매판 새로운 게임)
- **성운 시너지**: 같은 성운 펫 2마리 이상 → 해당 성운 보너스(예: 이그니스 성운 = 화상 데미지 +30%)
- **유물 시스템**: 행성 보스 처치 시 "유물" 획득. 전투 중 랜덤 버프/디버프
- **주간 시드 던전**: 매주 랜덤 규칙(예: 물속성만, 궁극기 쿨다운 절반) → 보상 차등
- **3연속 보스 러시**: 3마리 보스 연속 처치 모드 → 보상 누적

### C. 소셜 · 경쟁 콘텐츠
- **비동기 PvP**: 상대 덱과 AI 대전. 방어 덱 설정 + 공격 덱으로 도전
- **리그 시즌**: 브론즈/실버/골드/플래티넘/다이아몬드. 시즌 보상(스킨/유물/골드)
- **길드/클랜**: 길드 전쟁(행성 점령 공유), 길드 상점, 기부 보상
- **친구 대결**: 친구 덱 코드로 즉시 대전

### D. 시간제 콘텐츠 & FOMO
- **성운 일일 보스**: 4대 성운 순환 보스, 처치 시 한정 재화
- **행성 쟁탈전**: 12시간마다 특정 행성 쟁탈 → 참가자 전원 보상
- **교배 축제**: 주말 교배 비용 절반/고대 등급 확률 2배
- **매일 밤 10시 길드 보스**: 10분간 전원 참가, 랭킹 보상

### E. 수집 완성 욕구 강화
- **도감 세트 보너스**: 4기본종/4혼혈1세대/4G2 완성 시 영구 스탯 보너스
- **스킨 시스템**: 동일 펫이라도 외형/색상/이펙트 커스터마이징
- **업적 뱃지**: 도전과제 완료 시 프로필 뱃지
- **NFT 연동(기존 준비)**: 희귀 펫을 NFT로 민팅 → 거래/전시

### F. 스토리 · 세계관 몰입
- **행성 스토리 카드**: 행성 점령 시 1컷 스토리 + 보스 대사
- **종족 일기**: 교배로 새 종족 탄생 시 도감에 로어 추가
- **시즌 스토리**: "Season 1"에 메인 퀘스트 추가(은하계 정복 서사)
- **보스 등장 컷신**: 보스전 시작 시 짧은 연출

### G. 모네타이제이션 강화 (중독성과 균형)
- **배틀패스**: 무료/유료 보상 트랙(펫, 골드, 스킨, 유물)
- **스킨/이펙트 상점**: 궁극기 이펙트, 펫 외형, 배틀 배경
- **광고 보상**: 배틀 속도 2배(1시간), 즉시 수확, 추가 교배 횟수
- **한정 상점**: 주말/시즌 한정 팩

## 3. 우선 적용 3가지 (가성비 최고)

1. **즉시 배틀 + 연승 보너스 시각화** (개발 비용 낮음, 체감 큼)
2. **성운 시너지 + 유물 시스템** (기존 시스템에 자연스럽게 연결)
3. **비동기 PvP + 리그** (소셜 확산, 재접속율 상승)
