# PetForge 기능 상세 스펙 모음

## FS-001: 빠른 배틀 (Quick Battle)
**목적**: 30초 핵심 루프 완료
**트리거**: 홈 "⚡ 빠른 배틀" 버튼
**동작**:
1. 사용자의 최근 승리 덱 3마리를 자동 선택
2. 없으면 희귀도 높은 펫 3마리 + 성운 시너지 우선
3. 적은 현재 배틀 난이도 +1의 보통 적
4. 3배속 자동 전투
5. 승리 시: 골드, EXP, 연승 +1, 룰렛 1회

**UI**: 메인 버튼, 30초 타이머, 결과 요약

---

## FS-002: 연승 보너스 시각화
**목적**: 긴장감 + 보상 기대감
**동작**:
- 3연승: +30%, 불꽃 1단
- 5연승: +50%, 불꽃 2단
- 10연승: +100%, 불꽃 3단 (캡)
- 연승 중 배틀 버튼 테두리 발광
- 연승 끊기 1회 전 경고 토스트

**UI**: 배틀 버튼, 연승 카운터, 보너스 %

---

## FS-003: 승리 룰렛
**목적**: 보상 폭발 + 광고 수익
**동작**:
- 승리 후 자동 3슬롯 룰렛
- 보상 풀: 골드×1.5, 스킬 재료×1, 돌연변이 포션×1, EXP 부스트 30분
- 광고 시청 시 +2회
- 패배 시 "다음 승리에 룰렛" 미리보기

**UI**: 룰렛 모달, 광고 버튼

---

## FS-004: 성운 시너지
**목적**: 덱 빌드 전략화
**동작**:
- 덱 내 같은 galaxyId 펫 수에 따라 보너스
- 2마리: 속성 데미지 +15%, SP 회복 +10%
- 3마리: 속성 데미지 +30%, 궁극기 시작 +20
- 전투 시작 시 시너지 아이콘 표시

**데이터**: `planets.js`의 galaxyId 기준

---

## FS-005: 유물 시스템
**목적**: 매판 다른 느낌, 수집 완성 욕구
**동작**:
- 유물 슬롯 3개 (펫과 별개)
- 획득: 보스 처치, 행성 점령, 이벤트, 뽑기
- 강화: 성운 조각 소모 → 레벨업
- 예시 유물:
  - `빛의 잔해`: 빛 쿨다운 -1턴
  - `용암 심장`: 화상 +50%
  - `시공 조각`: 선공 보장
  - `행운의 별`: 크리 +15%

**UI**: 인벤토리 → 유물 탭

## FS-006: 비동기 PvP
**목적**: 소셜 경쟁, 재접속
**동작**:
- 공격 덱 / 방어 덱 분리 저장
- 상대 목록: 비슷한 점수대 10명
- 도전 시 AI가 상대 방어 덱 운영
- 결과 기록, 리벤지 가능

**UI**: 아레나 탭, 덱 설정, 상대 목록, 전적

---

## FS-007: 리그 시즌
**목적**: 장기 몰입
**동작**:
- 2주 시즌
- 점수 승급: 브론즈→실버→골드→플래티넘→다이아→마스터
- 시즌 종료 시 티어 보상
- 보상: 한정 스킨, 유물, 골드, 패스 XP

**UI**: 리그 탭, 티어 배너, 남은 시간

---

## FS-008: 배틀패스
**목적**: 매출 + 일일 활동
**동작**:
- 50단계, 무료/유료 트랙
- XP 획득: 배틀, 퀘스트, 교배, 행성 점령
- 보상: 골드, 스킨, 유물, 포션, 2배속 티켓

**UI**: 배틀패스 탭, 보상 미리보기

---

## FS-009: 도감 세트 보너스
**목적**: 수집 동기 + 전력 상승
**동작**:
- 4기본 종족 수집 → 전 펫 HP +3%
- G1 4종 → 전 펫 ATK +3%
- G2 4종 → 전 펫 DEF +3%
- G3 전체 → 크리 +5%
- 보너스는 영구 적용

**UI**: 도감 → 세트 탭
