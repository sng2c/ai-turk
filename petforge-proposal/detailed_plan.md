| 시간 | 경험 | 목표 |

## 1. A. 30초 핵심 루프 (즉시 보상 폭발)

### 1.1 "빠른 배틀" 메인 버튼
- 홈 화면 중앙에 **"⚡ 1분 배틀"** 플로팅 버튼 추가
- 클릭 시 최근 덱 또는 추천 덱으로 바로 전투 → 30초 내 종료
- 승리 시: 골드 + 연승 보너스 + EXP + **승리 룰렛 1회**

### 1.2 승리 룰렛 (Post-Battle Roulette)
- 승리 후 3개 슬롯 자동 회전: 골드×1.5 / 스킬 재료 / 돌연변이 포션 / 경험치 부스트
- 광고 시청(또는 이벤트 티켓)으로 +2회 추가
- **핵심**: 패배 후에도 "다음엔 룰렛" 기대감 유지

### 1.3 연승 보너스 시각화
- 현재 `streakBonusMax:100%` → 단계별 표시:
  - 3연승: 🔥 +30%
  - 5연승: 🔥🔥 +50%
  - 10연승: 🔥🔥🔥 +100% (캡)
- 연승 중일 때 배틀 버튼 주변에 불꽃 이펙트
- 연승 끊기 직전 경고: "1패하면 보너스 소멸!"

### 1.4 일일 첫 승리 2배
- 매일 첫 승리 시 골드/EXP 2배 배지
- 24시간 리셋 타이머 노출 → 다음 날 복귀 동기

### 1.5 배틀 속도 업그레이드
- "1배속 → 1.5배속 → 2배속 → 3배속" 해금
- 조건: 배틀 50회/100회/200회
- 광고/티켓으로 1시간 즉시 2배속

## 2. B. 성운 시너지 + 유물 시스템 (매판 새로운 게임)

### 2.1 성운 시너지 (Nebula Synergy)
덱 내 같은 `galaxyId` 펫 수에 따라 전투 중 항상 적용:

| 동일 성운 수 | 보너스 |
|--------------|--------|
| 2마리 | 해당 성운 속성 데미지 +15%, SP 회복 +10% |
| 3마리 | 속성 데미지 +30%, 궁극기 게이지 시작 +20 |

- 덱 빌드 가이드: "이그니스 성운 3마리 추천" 등 UI로 노출
- 시너지 활성화 시 펫 아이콘 테두리 발광

### 2.2 유물 시스템 (Relics)
- 보스 처치/행성 점령/이벤트로 유물 획득
- 유물은 **패시브 슬롯**에 장착 (최대 3개)
- 예시 유물:
  - `빛의 잔해`: 빛 속성 스킬 쿨다운 -1턴
  - `용암 심장`: 화상 데미지 +50%
  - `시공 조각`: 첫 턴 선공 보장
  - `행운의 별`: 크리티컬 확률 +15%

### 2.3 주간 시드 던전 (Weekly Seed Dungeon)
- 매주 월요일 00:00 랜덤 규칙 3개 생성
- 예시:
  - "물속성 펫만 출전"
  - "궁극기 SP 비용 절반"
  - "적 HP 2배, 보상 3배"
- 랭킹 보상: 유물, 골드, 한정 스킨

### 2.4 보스 러시 (Boss Rush)
- 3마리 보스 연속 처치 모드
- 중간에 회복 불가 → 전략적 덱 빌드 필요
- 클리어 시 보상 누적 × 시너지 보너스

## 3. C. 비동기 PvP + 리그

### 3.1 비동기 아레나
- 플레이어가 **공격 덱**과 **방어 덱** 각각 설정
- 상대 목록에서 도전 → AI가 방어 덱 운영
- 승리 시 토큰 + 점수, 패배 시 소량 보상

### 3.2 리그 시즌 (2주)
- 브론즈 → 실버 → 골드 → 플래티넘 → 다이아몬드 → 마스터
- 승급 조건: 일정 점수 도달
- 시즌 보상: 한정 스킨, 유물, 골드, 배틀패스 XP

### 3.3 친구 대결
- 친구의 "덱 코드"로 즉시 대전
- 친구 목록 + 최근 전적 + 리벤지 버튼

### 3.4 길드/클랜 (Guild)
- 20인 길드
- 길드 보스: 12시간마다 등장, 전원 참가
- 길드 기부: 골드 기부 → 길드 코인 → 길드 상점
- 길드 전쟁: 매주 다른 길드와 행성 점령 경쟁

---

## 4. D. 시간제 콘텐츠 & FOMO

### 4.1 성운 일일 보스
- 매일 00:00, 12:00 각 1종씩 4대 성운 보스 순환
- 처치 시 "성운 조각" 획득 → 유물 강화 재료
- 누적 피해량 랭킹: 전 서버/길드/친구

### 4.2 행성 쟁탈전
- 12시간마다 특정 행성이 쟁탈 대상으로 지정
- 참가자 전원 점령 기여도에 따라 보상
- 점령한 길드/개인에게 24시간 특별 버프

### 4.3 교배 축제
- 주마다 금/토/일 중 하루 "교배 축제"
- 교배 비용 절반
- 고대 등급 확률 2배
- 한정 교배-only 종족/스킨 노출

### 4.4 길드 보스 (Daily Guild Boss)
- 매일 밤 21:00, 10분간 길드원 전원 참가
- 개인 누적 피해 + 길드 전체 처치 보상
- 랭킹: 길드 내 1위 → 추가 유물

---

## 5. E. 수집 완성 욕구

### 5.1 도감 세트 보너스
- 4기본 종족 수집: 전 펫 HP +3%
- G1 혼혈 4종 수집: 전 펫 ATK +3%
- G2 혼혈 4종 수집: 전 펫 DEF +3%
- G3 고대 종족 전체 수집: 크리티컬 확률 +5%
- **수집 욕구 + 전투력 상승 동시에**

### 5.2 스킨 시스템
- 종족별 외형 변형: 색상, 아이콘, 이펙트
- 획득처: 리그 보상, 이벤트, 상점, NFT
- 스킨 장착 시 배틀/프로필/도감에 적용

### 5.3 업적 & 뱃지
- 분류: 전투, 교배, 수집, 탐험, 소셜
- 업적 달성 시 프로필 뱃지 획득
- 특정 뱃지 조합으로 추가 보너스

### 5.4 NFT 연동
- 기존 NFT 민팅 준비 UI 활용
- UR 등급 펫 또는 한정 스킨 NFT로 민팅
- 보유 NFT를 프로필/도감에 전시

## 6. F. 스토리 & 세계관 몰입

### 6.1 행성 스토리 카드
- 행성 최초 점령 시 1컷 일러스트 + 로어 카드 해금
- 카드 수집 → 도감 완성률 상승 → 보상

### 6.2 종족 일기
- 새 종족 탄생 시 도감에 "태어난 순간" 기록
- G3 고대 종족마다 고유 에피소드 3개

### 6.3 시즌 스토리 (Season Quest)
- "Season 1: 은하계 정복" 메인 퀘스트 20개
- 스토리 진행 보상: 골드, 유물, 스킨, 한정 펫

### 6.4 보스 등장 컷신
- 보스전 시작 시 짧은 연출 (2~3초)
- 보스 이름, 타이틀, 대사 노출
- 처음 보는 보스일 때는 컷신 자동 재생

## 7. G. 모네타이제이션 강화

### 7.1 배틀패스
- 무료/유료 트랙
- 보상: 골드, 스킨, 유물, 교배 포션, EXP 부스트
- 50단계, 2주 시즌

### 7.2 광고 보상
- 배틀 2배속 1시간
- 즉시 행성 수확
- 교배 횟수 +1회
- 룰렛 추가 2회
- 광고 시청 시 보상 ×2

### 7.3 한정 상점
- 주말 한정 팩: "고대 교배 팩"
- 시즌 한정 스킨/이펙트
- 골드/유료 재화 두 가지 가격

### 7.4 펫 보관소 확장
- 기본 보관 한도 50 → 유료 확장 200
- 수집형 게임에서 필수 구매 압력
