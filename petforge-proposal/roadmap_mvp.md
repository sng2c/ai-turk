# PetForge MVP 구현 우선순위

## Phase 1: 빠른 배틀 & 연승 폭발 (1~2주)
- [ ] 홈 화면 "⚡ 빠른 배틀" 버튼
- [ ] 최근 덱 또는 추천 덱 자동 구성
- [ ] 배틀 30초 내 종료 옵션 (3배속)
- [ ] 연승 보너스 시각화 (불꽃 이펙트 + %)
- [ ] 승리 후 룰렛 1회 (3 슬롯)
- [ ] 일일 첫 승리 2배 배지
- [ ] 배틀 속도 업그레이드 시스템

## Phase 2: 성운 시너지 & 유물 (3~4주)
- [ ] 덱 시너지 계산 로직
- [ ] 성운 보너스 적용 (전투 중 패시브)
- [ ] 유물 DB + 슬롯 UI
- [ ] 보스/행성에서 유물 드랍
- [ ] 주간 시드 던전 기초

## Phase 3: PvP & 리그 (5~6주)
- [ ] 공격 덱 / 방어 덱 분리
- [ ] AI 대전 기록 저장
- [ ] 리그 점수 + 티어
- [ ] 시즌 보상
- [ ] 친구 대결 (덱 코드)

## Phase 4: 시간제 콘텐츠 (7~8주)
- [ ] 일일 성운 보스
- [ ] 행성 쟁탈전
- [ ] 교배 축제
- [ ] 길드 보스

## Phase 5: 수집 & 몰입 (9~12주)
- [ ] 도감 세트 보너스
- [ ] 스킨 시스템
- [ ] 업적/뱃지
- [ ] 시즌 퀘스트
- [ ] 배틀패스

## 즉시 가능한 파일 수정 대상
- `petforge-analysis/skills.js` → 시너지/유물 효과 추가 시 참고
- `petforge-analysis/planets_all.js` → 행성 보상/보스 데이터 확장
- `petforge-analysis/jn_battle_turn.js` → 전투 로직 수정
- `petforge-analysis/game_provider_body.js` → 게임 상태 관리 확장
